# 🚀 Page Pulse

Page Pulse is a Flask-based web application that analyzes a webpage and generates a quick audit report.

## Features

- Analyze any website
- HTTP Status Code
- Response Time
- Page Title
- Meta Description
- H1 Tag Count
- Total Images
- Images Missing Alt Text
- Word Count
- Copy Report

## Technologies Used

- Python
- Flask
- Requests
- BeautifulSoup
- HTML
- CSS
- JavaScript

## Installation

```bash
pip install -r requirements.txt
python app.py
```

Open:

```
http://127.0.0.1:5000
```
